## What is Cobalt Prospect Engine?

Cobalt Prospect Engine is a web application built for prospecting, lead generation, and sales-oriented day-to-day work. It targets people who want a straightforward browser experience instead of installing a heavy desktop client.

The focus is a clear prospecting path so lead-related work stays structured. Because everything runs in the browser, you can use it wherever a compatible browser is available—handy for solo operators and teams that want a light footprint.
